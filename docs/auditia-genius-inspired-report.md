## Upgrade ciblé : rapports AuditIA plus orientés décisions

Cette branche n'ajoute pas de nouvelle API et ne change pas les scores, Supabase, l'authentification ni le workflow de scan. Elle améliore le rapport existant à partir des données déjà collectées.

### Principes
- Un encart de synthèse relie l'état SEO/GEO à une première priorité.
- Les estimations et les données non évaluées restent distinguées des mesures observées.
- Les recommandations doivent être actionnables, hiérarchisées et reliées aux éléments du rapport.
- L'export complet et express reste disponible.

### Référence
Inspiration fonctionnelle : rapport Genius Acquisition (analyse concurrentielle, canaux, SEO et plan d'action). AuditIA garde son identité et n'utilise ni leur code ni leurs textes.
